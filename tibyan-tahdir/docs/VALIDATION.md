# سجل التحقق · ١٨ أكتوبر ٢٠٢٦

## نجح

- `npm run check`: فحص صياغة ملفات JavaScript الثلاثة.
- `bash -n scripts/build-safari.sh`: فحص صياغة سكربت التحويل.
- `node --test tests/core.cjs`: أربعة اختبارات ناجحة للتواريخ وحدود الأسبوع، وتنقية المدخلات والروابط، وتصدير النص، واستخدام مخزن Safari.
- `node --test tests/integration.cjs`: ثلاثة اختبارات تكامل ناجحة في Chromium 153 وPlaywright 1.62.1 بعرض 390×844.

اختبار المكتبة يغطي البدء فارغًا، وحفظ درس من قالب وإعادة فتحه، وتوزيعه على شعبتين، ومنع تعارض حصة، وتصدير JSON وإعادة استيراده مع بيانات المعلم، وعدم تكرار السجلات ورفض الملف التالف. لم يظهر تجاوز أفقي لعرض الشاشة.

اختبار مكوّن الصفحة يغطي استبعاد حقول تسجيل الدخول والحقول المخفية، ومنع استبدال المحتوى الموجود دون اختيار صريح، ومعاينة وتعبئة النصوص ومحرر داخل إطار من المصدر نفسه، وعدم إرسال النموذج، والتراجع مع الاحتفاظ بتعديل يدوي لاحق. كما نجح رفض ربط عنصرين بالحقل نفسه وإلغاء التعبئة عند تغير الحقل بعد المعاينة. لم ينشئ المكوّن أي طلب شبكة في هذه التجربة.

راجعت صور الواجهة الرئيسية ولوحة التعبئة بعرض شاشة جوال. صفحات الاختبار كلها مصطنعة ومعترضة محليًا، وليست صورًا من حساب المستخدم أو من مدرستي الفعلية. استخدم الاختبار متصفحًا بديلًا متاحًا عبر حزمة QA بعد تعذر تنزيل متصفح Playwright الافتراضي؛ يمكن تمرير مساره عبر `TIBYAN_BROWSER_PATH` ووسائطه عبر `TIBYAN_BROWSER_ARGS`. حزمة QA ليست جزءًا من المنتج أو الاعتماديات.

## لم يُنفذ

- بناء مشروع Safari أو توقيعه: البيئة الحالية Linux، ولا تحتوي Mac/Xcode.
- تشغيل الإضافة على Safari أو جهاز آيفون فعلي.
- الدخول إلى حساب مدرستي أو التحقق من تسميات حقوله ومحرراته الفعلية.
- اختبار الطباعة أو الحافظة على الآيفون، أو التوزيع عبر TestFlight/App Store.

هذه النتائج تثبت سلوك الكود على الصفحة التجريبية، ولا تثبت تكامله الكامل مع مدرستي أو جاهزية تثبيت iOS.
