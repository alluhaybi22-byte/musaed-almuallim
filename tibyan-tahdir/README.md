# تبيان · مساعد التحضير

نسخة مستقلة 0.2.0 للمعلم محمد اللهيبي، مبنية على المصدر السابق 0.1.0. توفر مكتبة تحاضير عربية، وجدولًا أسبوعيًا، وتوزيع التحضير للشعب، ومساعدًا لتعبئة الحقول داخل مدرستي. لا تعتمد على خوادم تشغيل أو اشتراك، ولا تنسخ كود أو هوية «تحضيري».

## ما يعمل

- أربعة قوالب قابلة للتحرير: القراءة، الظواهر اللغوية، الإملاء والخط، والتعبير.
- إنشاء التحضير وتعديله والبحث والتكرار والنسخ والطباعة A4.
- توزيع تحضير واحد على عدة شعب ومواعيد، مع منع تعارض الشعبة والتاريخ والحصة في عملية التوزيع.
- جدول من الأحد إلى الخميس بحسب تاريخ الحصة.
- تصدير واستيراد JSON مع دمج التحاضير الجديدة دون حذف الموجودة؛ خيار مستقل لاستعادة بيانات المعلم والمدرسة. النسخ القديمة ذات الإصدار 1 مدعومة.
- لوحة تبيان داخل `https://schools.madrasati.sa/` لانتقاء التحضير وربط عناصره بالحقول الظاهرة ومعاينة النص ثم تعبئته والتراجع عن آخر تعبئة.
- عند وجود نص في الحقل يتطلب الاستبدال تفعيل خيار صريح. تغيّر الصفحة أو الحقول بعد المعاينة يبطل التعبئة. التراجع يحافظ على ما عدله المعلم بعد التعبئة.

## التشغيل على الكمبيوتر

1. فك الحزمة.
2. افتح `chrome://extensions` أو `edge://extensions` وفعل وضع المطور.
3. اختر تحميل إضافة غير مضغوطة وحدد مجلد `extension`.
4. افتح الإضافة وأعد تحضيرك واحفظه. من داخل مدرستي افتح إعداد الدرس واضغط «تبيان · التحضير».

يمكن فتح `extension/index.html` مستقلاً على الكمبيوتر لإعداد التحاضير محليًا. هذا الوضع لا يضيف لوحة إلى مدرستي. نسخة الملف ونسخة الإضافة تستخدمان مساحتين مختلفتين؛ انقل البيانات بينهما بملف النسخة الاحتياطية.

## الآيفون

هذه **شفرة إضافة Safari قابلة للتحويل وليست تطبيق IPA موقعًا أو مثبتًا**. لا يمكن تثبيت ملف ZIP كإضافة على الآيفون، ولا يمنح فتح صفحة ويب صلاحية تعديل صفحة مدرستي.

على Mac مثبت عليه Xcode:

```sh
bash scripts/build-safari.sh
```

افتح مشروع Xcode الناتج، وحدد فريق التوقيع ومعرف التطبيق والجهاز، ثم ابن وشغّل التطبيق. إن أظهر المحول ملاحظات توافق، عالجها قبل الاعتماد. فعّل الإضافة من إعدادات Safari وامنحها إذن موقع مدرستي. تسجيل الدخول يتم داخل الموقع نفسه. التوزيع عبر TestFlight أو App Store يحتاج حساب مطور Apple وإجراءاته؛ هذه الحزمة لم تُرفع إليهما. تفاصيل التشغيل في [دليل الآيفون](docs/IPHONE.md).

## حدود التكامل

الربط تجريبي، يعتمد على الحقول الظاهرة وتسمياتها، ولم يُختبر في حساب مدرستي فعلي أو Safari على آيفون. لا يفترض مسارات API أو معرفات داخلية للمنصة. عند غموض الحقول يختار المعلم الربط بنفسه. محررات النص داخل إطارات من نفس المصدر مدعومة؛ المحررات ذات المصدر المختلف والمحررات الخاصة غير القابلة للتحرير مباشرة تحتاج نسخًا يدويًا أو مواءمة لاحقة. إذا لم تجد الحقول، افتح صفحة إعداد الدرس واضغط تحديث.

التعبئة تخص الأهداف والتهيئة والأنشطة والاستراتيجيات والتقويم والواجب والإثراء ورابط المورد. لا تغير مسار المنهج أو الصف أو عنوان الدرس في المنصة، ولا تجلب واجبات عين تلقائيًا، ولا تحفظ الدروس أو تحضر أسبوعًا كاملًا داخل مدرستي. التوزيع الأسبوعي محلي. روابط عين والفيديو يضيفها المعلم؛ القوالب عامة وليست تحضيرًا رسميًا من المنهج.

## الخصوصية والحفظ

إذن `storage` فقط مع تشغيل مكوّن الصفحة في نطاق مدرستي المحدد. لا توجد مكتبات من CDN أو تحليلات أو طلبات شبكة في الكود. تُقرأ التحاضير المحلية والحقول النصية الظاهرة عند استخدام اللوحة؛ كلمات المرور وحقول تسجيل الدخول مستبعدة. النصوص المختارة تُكتب في صفحة مدرستي، وقد ترسلها المنصة إلى خوادمها عند الحفظ حسب سلوكها. لا تجمع الإضافة بيانات الدخول.

البيانات محلية للجهاز والمتصفح والإضافة، دون مزامنة. حذف الإضافة أو بيانات المتصفح قد يحذف التحاضير. صدّر نسخة احتياطية بانتظام، وتجنب تحرير المكتبة في نافذتين في الوقت نفسه. الحد ٢٠٠٠ تحضير و٥٠ ميجابايت لملف الاستيراد؛ السجلات الموجودة بنفس المعرف لا تستبدل أثناء الدمج.

## التحقق

```sh
npm install
npx playwright install chromium
npm run check
npm test
```

اختبارات تكامل Chromium بواجهة 390px: إنشاء وحفظ وإعادة فتح وتوزيع واستيراد؛ وتعبئة حقول ومحرر في إطار، ومنع استبدال غير مقصود، ورفض ربط مكرر، وإبطال معاينة قديمة، والتراجع مع حفظ التعديلات اليدوية. تستخدم صفحة مدرستي تجريبية محلية مع اعتراض كل الطلبات، ولا تتصل بالحساب أو المنصة. راجع [سجل التحقق](docs/VALIDATION.md) للنتيجة الفعلية.
