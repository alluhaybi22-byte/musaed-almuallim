# تشغيل المساعد ونشره

## تجربة الكمبيوتر

ابنِ النسخة بوساطة `npm run build:portable`. افتح `dist/Al-Musaed-Desktop.html` في Chrome أو Edge، ثم أدخل بيانات المدرسة في الإعدادات وأضف طلابك. الملف يحتوي على التطبيق والمنهج والصورة والخط؛ لا يتطلب خادمًا أو شبكة بعد تنزيله.

الحفظ على الجهاز، ولا توجد مزامنة بين الأجهزة. استخدم تصدير النسخة الاحتياطية في الإعدادات قبل نقل الملف أو تغيير المتصفح أو الانتقال إلى رابط الويب. دمج النسخة يتم من الإعدادات في الوجهة الجديدة. فتح الملف في تطبيق معاينة ملفات أو داخل نافذة المحادثة لا يعادل تشغيله في متصفح كمبيوتر عادي.

## Cloudflare

حالة ١٤ أكتوبر ٢٠٢٦: الاتصال الحالي يقرأ حساب Cloudflare، لكنه رفض رفع Worker باسم `musaed-almuallim` برسالة `No access to the specified resource`، حتى عند الرفع دون ربط سر. لم ينجح إنشاء Worker، ولم يُتحقق من رابط تشغيل حي. لا يفترض هذا السجل سببًا محددًا للرفض؛ يلزم اتصال مخول بتحرير Workers في الحساب الصحيح.

إعداد المشروع في `wrangler.jsonc` يستدعي بناء الملفات ثم حزمها داخل `dist/private-worker.mjs`. يمكن نشر هذا الموديول من أدوات Cloudflare الرسمية عبر اتصال مخول. عيّن سرًا باسم `PREVIEW_PASSWORD` قبل الاستخدام، ثم فعّل عنوان workers.dev الخاص بالمشروع. اسم مستخدم المعاينة `teacher`، وتُدخل كلمة مرور السر في مطالبة المتصفح.

لا تضع كلمة المرور في الكود أو ملف HTML أو المستودع. Worker يرفض جميع الطلبات دون السر. افحص الطلب دون مصادقة وتأكد من استجابة 401، ثم افحص الفتح بالمصادقة والاختبار والحفظ وPDF والتشغيل دون اتصال. لا يُرفع كشف الطلاب أو نتائجهم إلى Worker؛ هو يقدم ملفات التطبيق فقط.

## فحص الإصدار

- نجح ١٣ اختبارًا لمنطق النتائج والاستيراد والنسخ الاحتياطي وحماية ملفات المعاينة.
- نجحت تجربة المتصفح للتصحيح والاستكمال والتقارير والعمل دون اتصال والجوال ومسارات الفصل الثاني للثاني والثالث.
- نجحت تجربة الملف المحلي: طالب جديد، اختبار حرف مع الفتحة، نتيجة ١٠٠٪، وإعادة فتح مع بقاء البيانات، دون طلبات شبكة.

هذه نسخة أولى تجريبية. المهارات مبنية على دليل الوحدات لطبعة ١٤٤٨، والعينات معدة خصيصًا للبرنامج ويستطيع المعلم تعديلها قبل الاختبار. لا تمثل الحدود الافتراضية معيارًا وزاريًا معتمدًا.
