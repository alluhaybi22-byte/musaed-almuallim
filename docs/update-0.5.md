# تحديث 0.5.0

## الاستيراد

- قراءة أعمدة أسماء متجاورة عند تكرار رأس اسم الطالب، مع ربط ولي الأمر بأقرب عمود أسماء.
- إظهار كل جداول Word واختيارها افتراضيًا، مع خيار استبعاد أي جدول قبل الاعتماد.
- إظهار أوراق Excel وأعداد الأسماء واختيار أكثر من ورقة. تبقى أول ورقة مناسبة محددة افتراضيًا لتجنب خلط فصول مختلفة دون مراجعة.
- حفظ تعيين الأعمدة وأسطر العنوان لكل جدول/ورقة عند التنقل بينها.
- معالجة الخلايا المدمجة في Word والمسافات بين فقرات الاسم، وتجاوز الرؤوس المتكررة، وعدم قطع Excel عند 5001 صف.
- معاينة العدد الإجمالي قبل عرض القائمة الكاملة للتعديل والاعتماد. أول ستة أسماء في المعاينة ليست حدًا للاستيراد.

لا يتوفر كشف المستخدم الأصلي في هذه المحادثة؛ الإصلاح يغطّي أنماط نقص مؤكدة في الكود، وقد اختُبر بملفات تجريبية لا ببيانات الطلاب الفعلية.

## الاستماع والتدريب

- يبقى مشغل المقطع متاحًا في عرض الطالب دون النص والأسئلة والإجابات، ويحافظ على موضع التشغيل عند العودة للمعلم أو الانتقال إلى سؤال المقطع نفسه.
- تذكير غير مانع عند تقييم الاستماع دون توثيق تشغيل كامل أو قراءة المعلم.
- خطة تدريب قابلة للطباعة ضمن تقرير الطالب: تجمع الأخطاء والإجابات بمساعدة حسب المهارة والفرع، وتقترح نشاطًا وعينة ومعيار تحقق وموعدًا بعد أسبوع. لا تُدرج غير المقيم أو غير المدرس ولا تُصدر تشخيصًا آليًا.
- لا تغيير في صيغة البيانات أو نتائج الاختبارات السابقة أو التسجيلات التسعة.

## التحقق

- 33 اختبار منطق ووحدات.
- ملفات DOCX بجداول متعددة وخلايا مدمجة، وXLSX بورقتين، وXLS بعمودي أسماء؛ 25 اسمًا كاملًا لكل ملف في المراجعة والحفظ وإعادة الفتح، ومنع التكرار عند الاستيراد مجددًا.
- اختبار الجوال لاستمرار الصوت وإخفاء الأسئلة، وعد القراءة، وتعديل النص المشترك، والمسودة، وفك التسجيلات التسعة دون اتصال.
- اختبارات التطبيق العامة والتقارير والاستعادة ونسخة الكمبيوتر المستقلة.
