# جلسات الصف 0.11

الشاشة الرئيسية «صفي» تعرض الصف والشعبة وقائمة الطلاب، وزر بدء جلسة أو استكمالها. اختيار الفصل الدراسي والوحدة والدرس ثم نوع الاختبار يتم مرة واحدة لكل جلسة، والتفاصيل ضمن «تخصيص الاختبار».

تُحفظ النتائج تلقائيًا. زر التراجع يعيد آخر حكم ومعه الانتقال إلى الطالب السابق في عملية حفظ واحدة، ما دامت البيانات لم تتغير بعده. لا يمتد التراجع بعد إغلاق الصفحة. التجاوز يحتفظ بمسودة دون اختلاق نتيجة؛ ملخص الجلسة يعرض الطلاب المتبقين لاستكمالهم. تُعرض تقديرات الأداء كما اختارها المعلم، ونسبة الاجتياز منفصلة عنها دون تغيير طريقة احتساب النتائج السابقة.

## التشغيل المحلي

يتضمن المستودع بناء ملف HTML مستقل للكمبيوتر. الأمر `npm ci && npm run build:portable` ينتج `dist/Al-Musaed-Desktop.html`. انسخ الملف إلى مجلد ثابت وافتحه في Chrome أو Edge. الحفظ محلي في المتصفح؛ احتفظ بنسخة احتياطية دورية، وصدّر بيانات الرابط القديم ثم استعدها هنا. Google Drive خيار متصل بالإنترنت ولا يلزم للاختبار أو الحفظ المحلي.

فحص المتصفح للنسخة المستقلة يتحقق من فتح الملف، إجراء اختبار، استمرار النتائج بعد إعادة الفتح، وتشغيل التسجيلات المدمجة دون أي طلب إنترنت. يُرفق ملف النسخة المستقلة ضمن مخرجات GitHub Actions عند نجاح جميع الفحوص.

حالة النشر: هذا الفرع للمراجعة، ولم يُنشر إلى AppDeploy أو Cloudflare. تعذر استخدام اتصال Cloudflare الحالي لأنه يطلب إعادة تسجيل الدخول. تبقى إعدادات الخصوصية والحماية الحالية كما هي.
