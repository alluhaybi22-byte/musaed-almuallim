# تحديث المراجعة 0.3

التنفيذ: بطاقات بمهمة واحدة للظواهر والفهم، إجابات محددة للاستماع، معاينة وتعديل النص المسموع والإملائي ومعيار الحكم، تقرير البنود المتعثرة وفروع الظاهرة ومقارنة نفس العينات، تصفية النتائج وتقرير الصف حسب المهارة أو نفس الاختبار، مراجعة جميع أسماء الكشف مع تعديل واستبعاد، عرض الطالب، قوالب اختيار جاهزة، تذكير آخر نسخة احتياطية.

قبل النشر: قراءة المصدر المنشور، حفظ بنية بيانات الإصدار السابق، اختبار النتائج السابقة والمسودات، اختبار Excel/Word والمراجعة، حساب التقرير والتقدم مع استبعاد غير المقيم، اختبار عرض الطالب والرجوع وحفظ الملاحظة، بناء Vite والنسخة المستقلة، تحديث اختبارات QA وإرسال الملفات المتغيرة فقط، فحص حالة النشر حتى اكتمالها.

المعالجة محلية، بلا ذكاء اصطناعي وقت التشغيل أو رفع بيانات. الصور الموجودة في هوية التطبيق تبقى؛ العرض التعليمي يعتمد النص المشكول لضمان دقة القياس.

التدقيق النهائي: فصل نواتج القراءة والإملاء والفهم والتحويلات المركبة إلى أحكام مستقلة؛ عرض مهمة ومعيار كل بند متعثر؛ فتح تقرير الصف على أحدث عينات موحدة افتراضيًا؛ عدد البنود المقيمة ونطاق التاريخ في التقرير وCSV؛ ترشيح التاريخ بتوقيت الجهاز. نجح 24 اختبارًا للمنطق، واختبار الجوال على نسخة Vite، وتجربة النسخة المستقلة والعمل دون اتصال واستعادة نتائج الإصدار السابق.
